# Brand assets (Google Auth Platform)

| File                           | Use                                                                                     |
| ------------------------------ | --------------------------------------------------------------------------------------- |
| `google-oauth-logo.png`        | **Upload this** to Google Auth Platform → Branding → App logo. Exactly **120×120** PNG. |
| `google-oauth-logo-master.png` | 512×512 source for the OAuth plate (regenerate the 120px file from this if needed).     |
| `wordmark-lockup.png`          | Horizontal lockup for marketing / docs (not for the Google square upload).              |

The compact circular TX seal lives at `/logo.png` and `/logo.svg` for the in-app header and favicon. Google brand verification requires a logo that **uniquely identifies Da Nang TechX** (readable brand name), so do not upload `/logo.png` alone.

App name on the consent screen must be **`Da Nang TechX`**, matching `site.name`, homepage SSR text, and the `application-name` meta tag.
